# VSU OBE MIS

**Outcomes-Based Education Management Information System** for Visayas State University.

OBE MIS will bring the Outcomes-Based Education lifecycle into one system: program and course outcomes, curriculum mapping, OBE syllabi, assessment, outcome attainment, and continuous quality improvement (CQI) in support of quality assurance and accreditation.

## Plan

| Phase | Focus |
|---|---|
| **Research proposal** | Planning, requirements analysis and system design |
| **Year 1** | Outcomes, curriculum mapping, OBE syllabus builder |
| **Year 2** | Assessment results and outcome attainment |
| **Year 3** | Analytics and CQI |

## Status

🟡 **Research proposal: Planning** (since November 2026)
